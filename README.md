# Escape Room: Misión desactivar la bomba

Versión web interactiva del escape room en español (12.11.2026). Los detectives tienen 60 minutos para resolver 13 tareas, descifrar el mensaje secreto y desactivar la bomba.

## Cómo se juega

1. Pulsar **¿Están listos para aceptar la misión?** para poner en marcha el reloj.
2. **Paso 1:** resolver las 13 tareas. Cada respuesta da un número.
3. **Paso 2:** se abre al terminar las tareas. Convertir los números en letras y ordenarlas.
4. **Paso 3:** responder al mensaje secreto y convertir la respuesta en el código final.
5. **Paso 4:** escribir el código en el teclado de la bomba y pulsar OK.

El reloj se puede pausar y el progreso se guarda en el navegador. **Reiniciar** borra todo y vuelve a empezar.

## Abrirlo

- En el ordenador: abrir `index.html` con el navegador.
- En internet: activar GitHub Pages en *Settings → Pages*, con la rama `main` y la carpeta `/ (root)`.

## Archivos

```
index.html        la página completa (estilos y lógica incluidos)
assets/img/       ilustraciones de las tareas
```
